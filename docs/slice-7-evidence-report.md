## Authentication decision

The release includes polished `/welcome`, `/login` and `/signup` surfaces. The approved local Slice 3 Auth configuration intentionally keeps public registration disabled. Slice 7 therefore proves Signup presentation and deterministic client validation, then uses the committed no-context Alex identity for the authenticated account-to-onboarding release path. It does not weaken global Auth security merely to make a UI test create a new credential.

Public signup is not operational in the approved demonstration environment. A completely new public visitor cannot create a real account through self-service registration.

In an environment where public registration is deliberately enabled, the same Signup provider boundary supports immediate-session routing to onboarding or a neutral email-confirmation state. Raw Supabase errors are never rendered. This environment-specific registration switch remains an operational limitation, not hidden evidence.

## Remaining limitations and post-MVP recommendation

- Public registration is disabled in the approved local Auth configuration; deployments must make an explicit registration/confirmation decision.
- Live-model interpretation quality is not verified.
- No authoritative employer-benefit catalogue exists; Benefits correctly remains sparse and informational.
- Only Chromium was run. Manual VoiceOver/NVDA and optional Firefox/WebKit review would increase release confidence.
- Alignment is close and reference-led, not measured pixel-perfect reproduction.
- Global coverage is reported honestly; database/provider adapters are primarily covered through integration boundaries rather than unit percentages.

Recommended post-MVP priorities, outside the approved MVP: first authorise and run the existing live-provider corpus; then perform manual assistive-technology and optional cross-engine review; only after those gates should product discovery choose among employer-data verification or a newly specified simulator capability. No post-MVP item was started in Slice 7.
